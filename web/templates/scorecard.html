Model tool-calling scorecard

What is this page? Think of it like a driving test for your downloaded AI models. In the Workbench, an AI model can use "tools" to fetch real security data (look up a computer in CrowdStrike, search Jira tickets, run a Sentinel query, and so on). But some models are good at using those tools and some are terrible at it.

This page gives every model the same set of test questions and grades how well it uses the tools. That way you can see, at a glance, which model is actually good enough to trust for real work — instead of guessing.

It's safe to run: the test uses fake, pretend data, so it never touches your real CrowdStrike, Sentinel or Jira. Same test every time, so the scores are fair to compare.

Results

Each score is a percentage — higher is better. Here's what the columns mean:

Tool selection
Did the model reach for the right tool for the question (e.g. use the CrowdStrike lookup when asked about a host)? And did it correctly use no tool when none was needed?
Params
"Params" = parameters, the details a tool needs. If the question says "look up host DC-EAST-01", did the model pass DC-EAST-01 to the tool, and not something it made up?
Completed
Did the model finish cleanly and give a final answer, without erroring out or getting stuck?
Overall
A single combined grade (weighted: tool selection 50%, params 30%, completed 20%). This is the number to compare models by.
